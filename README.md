## 1. 项目背景 (Background)

对于高位截瘫或重症神经肌肉疾病患者，呼吸衰竭和睡眠呼吸暂停是威胁生命的核心风险。

* **技术痛点：** 传统居家看护设备多依赖血氧饱和度（$SpO_2$）阈值报警。然而研究表明，从呼吸停止到血氧仪检测到数值下降存在 **20-40秒的生理延迟**（循环滞后）。若仅以此作为干预前提，具有显著的“迟发性”，极易错失最佳救治时间。

## 2. 核心创新：多模态同步触发逻辑 (Core Innovation)

**灵息 (InspiraLink)** 引入了更具前瞻性的“感知-决策”架构，实现了从“后果报警”向“过程干预”的跨越：

* **零延迟同步：** 采用高精度数字化气压传感器 **BMP280**，通过鼻腔导管捕捉 Pa 级的微弱压力波动。该方案直接感应患者的吸气努力，实现毫秒级的泵气触发，解决了人机同步性问题。
* **多模态闭环：** 整合脉搏血氧监测（MAX30102）与环境温湿度感知（AHT20）。血氧数据不再是单一的触发点，而是作为评估通气效果、自动调节泵气强度的关键负反馈指标。

## 3. 系统功能架构 (System Architecture)

系统以树莓派 (Raspberry Pi) 为核心，结合嵌入式实时控制逻辑：

* **呼吸监测模块：** 基于 BMP280 的动态阈值算法，实时分析呼吸波形，自动滤除环境气压波动干扰。
* **动力执行模块：** 采用大力矩舵机驱动简易呼吸球囊（Ambu Bag），通过杠杆机构实现被动通气支持。
* **双轨安全策略：** * **同步轨：** 检测到自主吸气信号时立即辅助泵气。
* **备用轨（窒息模式）：** 若连续 15 秒未检测到气流信号，自动切入强制指令通气模式。


* **智能交互层：** 融合 AI 语言模型，实现病人生命体征的数据分析，并支持生成自然语言形式的健康监控报告。

## 4. 关键技术优势 (Technical Advantages)

1. **高灵敏度：** 采用数字压力采样技术，相比普通血氧报警，响应提前 20 秒以上。
2. **抗干扰性：** 通过软件滤波与移动平均算法，克服了环境噪声对传统声学或热敏呼吸检测的干扰。
3. **低成本原型：** 选用通用工业级传感器，在极低成本下实现了复杂的临床级同步触发逻辑演示。

## 5. 项目愿景 (Vision)

**灵息 (InspiraLink)** 致力于探索“具身智能”在智慧医疗领域的应用，通过多模态数据的深度融合，为瘫痪病人的呼吸安全提供一道实时、精准、有温度的科技防线。
